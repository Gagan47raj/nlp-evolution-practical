# NLP Evolution Practical

A hands-on journey through the evolution of Natural Language Processing, implemented primarily in Python and PyTorch.

## Objective

The goal of this repository is to understand NLP by progressively implementing practical systems, starting from traditional text processing and statistical methods and moving toward neural networks and modern Transformer-based NLP.

## Methodology

Each phase follows:

1. Understand the practical problem
2. Load or create data
3. Implement the technique
4. Experiment with the implementation
5. Evaluate the result
6. Visualize important results
7. Understand limitations
8. Connect the limitation to the next NLP technique
9. Commit the completed phase to GitHub
